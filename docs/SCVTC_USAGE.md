# Lumen 课程表使用说明

想集中查看课表、成绩、考试和学分，可以选 Lumen；更习惯以课程编辑和作息为中心，可以选 [Gnomon](https://github.com/zwwd1/gnomon-timetable)。不必两款都装，按自己的使用习惯选。

下面使用 2026 年 10 月 10 至 12 日的真实手机截图：登录与课表设置来自用户实机反馈，成绩页来自实机调试。没有账号、密码或个人成绩；截图早于这次英文改名与新版使用指南。

## 1. 第一次打开，连接川职教务

已有应用直接覆盖安装，保留原数据。第一次打开且没有账号、课表和查询记录时，会弹出连接邀请。选择连接学校，在应用页面输入学号和学校统一认证密码，再点“登录并自动同步”。

<img src="images/login.jpg" width="300" alt="Lumen 真机登录页：学号、学校密码、登录并自动同步和官方认证入口">

正常登录只需在这里输入一次。密码按账号加密保存在手机，后续复用会话；过期时尝试后台恢复。换手机、清数据或学校改密码后，需要重新连接。学校要求验证码、二次认证或处理账号安全提示时，点“打开学校认证页”，在官方页面完成。

学生身份核验通过便返回应用，先保存课表，成绩等信息随后读取。已有本机记录可以直接查看，不必每次等整套查询完成。

## 2. 查看课表，先补好节次时间

底栏“课表”切换日、周视图，点课程查看完整详情。右上角三点菜单提供同步、导出、添加课程、小组件和课表设置入口；设置中也可以打开“当前课表详情设置”。

<img src="images/schedule-settings.jpg" width="300" alt="Lumen 真机课表设置：课前提醒、周末显示、显示密度与桌面组件">

在课表设置中核对所选学期、开学日期和节次时间，再设置提醒。图中的“全部开启 / 全部关闭”只作用于当前账号所选学期的课程；新课程的提醒默认关闭，可逐门调整。

周末显示和显示密度影响课表布局，课程完整名称和地点仍可在详情中查看。未设置的节次需要按学校实际作息填写，不能依靠截图里的其他手机设置。

## 3. 查看成绩与考试

从课程首页进入“成绩与考试”，也可以把成绩加入底栏。页面按“学期 / 总体 / 考试”切换；更换学期会筛选已经保存的完整成绩，不重复请求整份报告。需要更新时点右上角刷新。

<img src="images/grades-empty.png" width="300" alt="Lumen 真机成绩页：当前学期暂无记录，可切换学期、总体和考试">

这是学校尚未返回当前学期成绩时的界面。“暂无学期成绩”和“读取失败”是两种状态；当前学期没有成绩，可以查看往期或总体成绩。已有数据先显示缓存，失败不会抹掉它。

学分页分别展示学校返回的毕业要求和成绩所得学分。重修按课程代码合并；未知数据不当作零，应用也不代替学校认定毕业资格。

## 4. 调整外观与常用入口

设置 → 外观中可以换壁纸、切明暗主题、调整玻璃参数、开关入场动画，并增减底栏入口。设置入口保留，底栏最多五项。默认背景是简洁的浅、深两张“留白”，已经选择的照片继续保留。

教务同步与备份页可以查看连接状态、成功时间和本地文件入口。应用后台按周期尝试更新，执行时间受 Android 调度和手机后台限制影响；需要最新信息时手动刷新。选课、评教等需要提交的业务，在学校官方页面由本人确认。

AI 助手使用你自己配置的模型服务，课程附带默认关闭。普通课表导出不包含登录凭据；云服务目前暂停，两款应用各自保存数据。

## 遇到问题

| 现象 | 可以怎么做 |
| --- | --- |
| 首次连接很慢 | 等页面给出结果，也可取消或进入学校认证页；不要连续重复提交密码 |
| 学校要求补充认证 | 在官方页面完成验证码或必要操作，再回应用继续同步 |
| 有课表但没有成绩 | 查看当前学期是否确实为空；需要更新时单独刷新成绩 |
| 后台没有及时更新 | 检查联网和后台权限；任务排队不等于同步完成 |
| 升级后需要重新登录 | 确认是否卸载、清数据、换手机或改过学校密码 |
| 换手机或需要备份 | 导出课表与设置，在新手机重新连接学校；旧密文不能代替登录 |

我不会实时维护。学校哪天改接口，应用可能就不好用了；源码在这里，可以 fork，自行 vibe coding。反馈问题时只发必要的版本与错误信息，别公开账号、密码和登录截图。
