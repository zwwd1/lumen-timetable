# 1.2.6 登录与成绩页修正

两版共用学校认证适配。1.2.5 中，身份确认后的学期查询仍属于登录完成条件；学期接口失败或等待过长，会让已经通过的学校认证继续停在“正在连接”。本次把身份确认与后续数据读取分开。

## 登录页

填写学号和密码后，只等待学校身份核验。通过后返回应用，真实学期、课表与成绩继续在后台读取。官方页面完成认证时，也不再等待学期接口才返回。同步失败保留原数据。

等待时可以取消或打开官方认证页。取消会关闭当前请求，切换官方页面前等待隐藏认证任务退出，避免两个浏览器同时改变会话。重试保留输入；记住的密码按账号匹配，不会在编辑学号时反复覆盖正在输入的其他密码。页面旋转继续观察后台任务，进程中断后显示重试提示。

验证码、账号安全提示、学校未接受账号密码和连接失败分别处理。学校要求人工确认的步骤留在官方页面，不自动跳过安全设置。身份请求上限为 12 秒，自动认证总等待上限为 55 秒；使用可取消的 OkHttp 回调，取消会关闭连接。

## 学校页面

匿名 GET 确认学校当前 SSO 返回的 `service` 与手机页面脚本。H5 页面由 Vue / iView 渲染，没有 HTML form，官方按钮依次处理账号检查、密码加密和认证跳转。代码继续使用该按钮，不自行猜测密码接口。

隐藏 WebView 按屏幕尺寸布局，后台适配仅放宽已确认 CAS 面板的可见区域判断。未附着窗口时控件区域可能为空，这是从源码和公开页面布局作出的判断，尚未在设备上复现。域名、服务地址、控件数量与学生身份校验继续保留。学校回调失败时只尝试一次实际教务首页，仍要取得匹配的学生身份才算通过。

## 成绩闪退

用户提供的 1.2.5 堆栈使用本版本 R8 mapping 还原，异常来自 `GradeSemesters.forSemester`，由 `AcademicGradesRoute` 的界面协程调用。往期成绩已有缓存、当前学期为空时，原函数把本地筛选当成远程单学期响应校验并抛出异常，异常逃出协程造成退出。

现在使用 `selectSemester` 处理本地完整报告，允许选中的学期没有成绩；远程单学期响应仍保留“学校返回其他学期”的校验。先显示缓存，切换学期在本地完成，已有成绩不会因为当前学期为空被丢弃。

## 验证范围

本次完成源码诊断、准确 mapping 还原和学校公开资源检查。编译、APK、平台与发布检查见 [验证记录](../VERIFICATION.md)。按用户要求，未连接手机、未运行应用功能或性能测试；真实自动登录、官方认证交接、键盘布局和成绩页仍需使用者确认。编译通过不能替代实机验证。

WebView 生命周期处理参考 [Android 官方文档](https://developer.android.com/develop/ui/views/layout/webapps/managing-webview)。
