# 图标与默认背景

晷与璟使用各自的原创二次元头像：晷以墨蓝头发和日晷发饰对应课程与时间，璟以银发与玉色发饰对应学习和玉光。资源通过图像生成工具创作，按 Android 的桌面密度导出；自适应图标保留前景、背景和单色层。

默认背景为原创浅深两张“留白”，以低对比的弧线留出阅读空间。只替换内置预设，不修改用户选择的照片。玻璃预览与首页使用同组背景。

校园助手小澄继续使用项目此前生成的五张原创状态图，微笑、侧目、眨眼、思考和回应均保留。已有状态图转为 WebP 时逐像素核对 RGBA，保持透明通道与原尺寸；新桌面图标按密度缩放，背景使用 WebP 编码。上游组件的许可证和必要版权说明仍保留。
