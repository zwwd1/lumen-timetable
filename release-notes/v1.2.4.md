# 璟 1.2.4

课业有迹，日常有光。

- 应用更名为璟，桌面换上原创头像。
- 默认背景改为简洁的日夜留白，自选照片保留。登录表单修正键盘留白和内容裁切，输入过的密码在本机加密记住。
- 第一次安装且没有记录时，先弹出连接邀请；覆盖安装继续使用原有数据。
- 成绩页先展示缓存，没有记录时显示读取状态。切换学期在本地筛选完整成绩，不再重复请求同一份报告。
- 启动入场动画可开关，底栏常用入口可增减；原有玻璃与回弹参数继续由用户调整。
- 增加更小的 arm64 安装包，同时提供包含全部架构的通用包。两种包功能与签名一致，可以互相覆盖升级。

云服务继续暂停。构建与安装包检查见 [验证记录](../VERIFICATION.md)；本轮没有连接手机，学校登录和界面体验由用户验收。
