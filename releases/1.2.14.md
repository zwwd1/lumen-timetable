# Lumen 课程表 1.2.14

这次主要处理切页时多余的页面更新，并把动效开关说明白。

• 切页结束状态仅在变化时通知页面，减少动画期间的重复重组；位移、淡入、折射与回弹效果保留。
• 外观参数显示系统动画是否开启，提供系统设置入口；入场动画、减少动态效果与底栏光学参数仍可分别调整。
• 川职账号卡移除不适用的旧配额和“更新 Cookie”入口；自动恢复与同步状态统一在教务同步页查看。
• 修复实机断网刷新时错误卡被底栏遮住、与重复提示叠在一起的问题；改为简短说明与重试，不直接显示底层网络异常。
• GitHub 首页与使用说明改为实机图文操作：连接学校、看课表、查成绩、调整效果和导出文件。
• 同步卡片明确区分最近任务与当前页面的数据保存时间，避免把考试完成误读为学分刚刷新。
• 修正外观参数滚动时内容穿过固定标题的问题。
• 修复自定义底栏时设置页意外关闭的问题，清理川职账号管理里不适用的配额提示。

沿用原包名和签名，保留数据覆盖安装。1.2.12、1.2.13 是 Gnomon 的独立迭代，未把它们写成 Lumen 的发布历史。

已在 Redmi K40 / Android 13 覆盖复测。具体通过项与未验收项见验证记录；受控后台成功不等同于所有系统状态下都能按时运行。

安装包：**Lumen-Timetable-1.2.14.apk**，17.65 MiB。
