# 璟 1.2.5

这一版处理 1.2.4 中用户反馈的连接、布局与安装包体积问题。

- 首次连接邀请按本机记录判断，清除数据后重新出现，不再依赖安装时间。
- 川职登录直接进入教务 SSO，保留学校返回的认证回调。本机密钥失效时恢复新写入，已有课表与密文保留。
- 教务同步页的标题与内容顺序排布；赞赏入口移到“致谢与关于”。设置页与更新通知统一使用“璟”。
- 默认川职包保留课表、成绩、学分、官方认证、编辑、提醒、组件、AI 和玻璃动效，使用系统 WebView。专用 Gecko 与 ONNX 移入完整插件平台包，源码和原模型保留。
- 两种分发沿用相同包名、原签名与数据格式，均提供通用和 ARM64 文件。应用内更新保留当前包的分发类型。

需要普通校园功能时选 `scvtc-zhixue-1.2.5.apk`，64 位 ARM 手机也可选 `arm64-v8a` 文件；需要专用第三方扩展时选带 `platform` 的文件。

Release 构建和安装包检查以本版本的验证记录为准。未连接手机调试，真实学校登录与过期恢复仍由使用者验收。
